# dispr

Windows のタスクトレイに常駐し、画面ロックやスリープを防止するユーティリティアプリです。

Win32 API の `SetThreadExecutionState` を使用して、ディスプレイのオフやスクリーンロックを抑制します。

## 機能

- 画面ロック（ディスプレイオフ）の防止（`ES_CONTINUOUS | ES_DISPLAY_REQUIRED`）
- オプション: スリープの防止（`ES_SYSTEM_REQUIRED`）
- オプション: AC 電源接続時のみ有効化（バッテリー駆動中は自動で一時停止）
- ログイン時の自動起動（レジストリ `HKCU\...\Run` で管理）
- 多重起動防止（Mutex）

## 必要環境

- Windows 10 / 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## ビルド

```bash
dotnet build
```

リリースビルド（単一 exe ファイルを生成）:

```bash
dotnet publish -c Release
```

## 使い方

ビルド後に生成される `dispr.exe` を実行すると、タスクトレイにアイコンが表示されます。

右クリックメニューから操作します:

| メニュー                          | 説明                                 |
| --------------------------------- | ------------------------------------ |
| 画面ロックを防止する              | メイン機能のオン/オフ                |
| オプション > スリープも防止する   | スリープも合わせて防止する           |
| オプション > AC電源接続時のみ有効 | バッテリー駆動中は機能を一時停止する |
| オプション > ログイン時に自動起動 | Windows ログイン時に自動で起動する   |
| 終了                              | アプリを終了する                     |

設定はレジストリ `HKCU\SOFTWARE\dispr` に保存されます。
